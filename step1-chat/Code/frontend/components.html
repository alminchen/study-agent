ToolTracePanel.vue

props
名说明
stepsToolTraceStep[]（App 的 toolTrace）
confirmEnabled?流式中才允许点确认（会话仍挂着 wait）
emits
confirm: [{ confirmId, toolCallId, action: "allow"|"deny" }]

App → resolveToolConfirm → POST /api/chat/confirm。

helpers
函数作用
titleOf(step)按 kind 生成中文标题（检索调用 / 等待确认 / 注入 / 泄露拦截…）
payloadOf(step)给 <pre> 的 JSON 主体（arguments / result / rules…）
canConfirm(step)confirmEnabled 且 pending_confirm 且 status===pending
onAllow / onDenyemit confirm payload
  1. 无 steps → 整段 v-if 不渲染。
  2. pending 项左边 amber 条；可确认时显示允许/拒绝按钮。
  3. resolving / allow / deny 显示对应 hint，禁用重复点击。
确认必须在 isStreaming 时点：服务端 ConfirmSession 随请求存活，流结束后 dispose。
