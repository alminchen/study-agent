关键处理函数

submit(content?)
  1. 取 content 或 input，trim；空或 isStreaming 则 return。
  2. 清空 input → await send(text)（useChat）。
handleKeydown

Enter（非 Shift、非 isComposing）→ preventDefault + submit。

handleCite(messageId, n)

写入 citeFocus；RagHitPanel 滚到对应注入段。

toggleRagMode / toggleSearchKb / toggleMultiAgent

分别调 setRagMode / setSearchKb / setMultiAgent。流式中顶栏/选项 disabled。

「资料问答」切端点到 /api/rag/chat；「多 Agent」切 /api/chat/multi； 「搜索知识库」只改请求体 searchDocs，不改路由——三者正交。

模板结构

topbar（品牌 · mode badge · 资料问答切换 · 模型 select · retry · clear） → main.chat（空态 starters 或 ChatMessageItem 列表） → RagHitPanel（仅 ragMode） → ToolTracePanel（非 ragMode；@confirm → resolveToolConfirm） → UsagePanel → error-banner → composer（textarea · 停止/发送 · 多 Agent / 搜索知识库复选）
RAG 时隐藏工具过程面板（资料问答另有 hit 面板）；普通对话才需要确认按钮与 tool Trace。

src/rag/citations.ts

ContentPart
{ kind:"text", text } | { kind:"cite", n, valid }
splitCitedText(content, validIndexes)
  1. 正则 /\[(\d+)\]/g 扫描。
  2. 夹缝推 text；匹配推 cite，valid = Set.has(n)。
  3. 模型瞎写的 [9] 若未注入 → valid:false，按钮 disabled。
引用必须对齐「本次 prompt 注入编号」，防止幻觉引用当依据。
validPromptIndexes(hits)

收集 hits 里非 null 的 promptIndex 成 Set。

findHitByPromptIndex(hits, n)
